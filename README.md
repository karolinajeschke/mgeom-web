# mgeom-web

Website for MGEOM (mgeom.cz), rebuilt from the Webflow site.

The website (deploy only these):

- `index.html`: homepage
- `subpages/`: project detail pages linked from "Realizované projekty"
- `css/style.css`: the one stylesheet every page links to
- `images/`: photos, plans, icons and logos (local copies, nothing loads from Webflow)

Working documents (never deployed):

- `docs/handoff.md`: what changed, how to preview, what is left before launch
- `docs/evaluation.md`, `docs/hodnoceni-webu.md`: evaluation of the old site and the new build
- `docs/mgeom-hodnoceni-webu.pdf`, `docs/mgeom-evaluation-infographic.pdf`: the same for the client
- `docs/inspiration/`: design brief and screenshots of the old Webflow site

`.pages.yml` and `data/` are the Pages CMS configuration and stay at the top level.
